# תחליפים נפוצים לסיגריות 🚭

ריכזנו כאן רשימה של תחליפים ודרכי סיוע לגמילה מעישון:

## מוצרים פיזיים
- **מדבקות ניקוטין** — מדבקות ברמות שונות שמודבקות על העור ומשחררות ניקוטין לאורך זמן
- **מסטיקים/סוכריות ניקוטין** — מעניקים מענה לצורך פיזי").
- **משאפים (Inhalers)** — מכשירי שאיפה להפחתת דחף
- **תרסיס ניקוטין** — תרסיס לאף/פה להפחתת חשק

## פתרונות דיגיטליים
- **אפליקציות ייעודיות להפסקת עישון**:
   - Quit Genius
   - Smoke Free
   - Flamy
   - Kwit
   - Youper
- **בוטי תמיכה/וואטסאפ** — בוטים שמעודדים ומדריכים בתהליך

## טיפול ותמיכה
- **קבוצות תמיכה (פייסבוק, פורומים, עמותות)**
- **ייעוץ רפואי (רופא/ת משפחה, רופא ריאות)**
- **סדנאות גמילה בקופות החולים ובקופות בריאות**

## עזרים נוספים
- **Vape (אידוי/וייפ) ללא ניקוטין**
- **צמחי מרפא, כדורי לעיסה, 'קיסמים' מיוחדים**
