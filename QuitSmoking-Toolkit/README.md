# QuitSmoking-Toolkit

מאגר קוד פתוח המאגד כלים, מדריכים, תיעוד וקהילות להפסקת עישון ולהפחתה בשימוש בניקוטין. כאן תמצאו תחליפים לסיגריות, מידע אובייקטיבי ומסלולים פרקטיים שמאפשרים להיגמל מעישון.

## מה יש במאגר?
- רשימות כלים טכנולוגיים (אפליקציות, אתרים, בוטים)
- מידע על מוצרים (סוכריות, מדבקות ניקוטין, תרסיסים, Vape וחילופיות אחרות)
- קהילות תמיכה וייעוץ
- מדריכים מקצועיים, מאמרים ועדויות אישיות
